# Issue #63：答题复盘与原题重做设计

日期：2026-10-13  
状态：需求决策已确认，尚未实现  
来源：[GitHub Issue #63](https://github.com/longzhuzhu/quiz-app/issues/63)；用户确认 Q1–Q6，随后要求停止追问并采用其余推荐决策。

## 目标与范围

用户结束答题后，能够区分正确、错误与未答，查看完整题干、选项、最终选择及当场正确答案，并按原题原序另开一场练习。所有模式统一完成页与复盘规则，模拟考试结束前继续隐藏答案和对错。

覆盖顺序练习、随机练习、模拟考试、错题练习、专项练习；包括刚完成后的入口、答题历史入口，以及累计错题的题目详情。本文记录需求和设计约束，不授权实施源码修改，不代表回归测试已经通过。

## 已核实的问题与证据

| 问题 | 当前实现依据 |
| --- | --- |
| 模拟考试完成后，每题仍缺对错与正确答案 | `backend/app/api/routes/quiz.py` 的 `session_detail` 只按 `mode == "exam"` 隐藏字段，没有区分完成态 |
| 缺失对错被画成答错 | `frontend/src/views/QuizResultView.vue` 把缺失的 `a.is_correct` 走错误分支 |
| 完整详情不可查看 | 结果页固定 `max-w-lg`，题干截断，列表限制高度，没有完整详情入口 |
| 漏答与题号不可靠 | 完成后只返回已答记录；答案查询未按 `session.question_ids` 排序，结果页却按答案数组下标编号 |
| “查看错题”范围不符 | 完成页进入考试项目累计错题本，而非本场错误题 |
| “再来一次”重新选题 | 只传 `bank_id` 和模式，未保留原题、题数、顺序或考点；跨题库错题会话的 `bank_id` 只是首个题库 |
| 历史内容可能失真 | `QuizSession` 保存题目 ID，`QuizAnswer` 保存选择和判定；历史读取当前题库，删除题目还会删除该题作答记录 |

证据等级：源码与文档核查；另有纯内存 `MagicMock` 函数级检查，验证已完成模拟会话的统计存在但答案仍缺 `is_correct`。未执行浏览器端到端复现或产品回归测试。

## 1. 完成页与统一复盘

- 完成页提供“查看详情”“本次错题”“再来一次”和“返回首页”；不再把完整题目压缩到截断的滚动列表。
- 查看详情、查看本次错题与已完成历史会话进入同一套复盘体验；未完成会话进入继续答题，不能借结果页提前查看答案。
- 复盘沿用现有答题页的一题一页、上一题／下一题和题号导航。桌面使用题号侧栏与题目区域，手机单列并保留可访问的题号导航；长题干、选项不得截断或被固定导航遮挡。
- 本场复盘支持全部／正确／错误／未答筛选；“本次错题”默认选中错误筛选。筛选后保留原场题号，不按筛选数组重新编号。
- 无错误或其他筛选为空时展示明确空状态；不得跳到累计错题本补内容。
- 原场完整题目顺序是唯一编号依据；跳题、回头改答和数据库记录顺序不改变题号。

## 2. 只读与辅助能力

- 复盘显示原场最后一次成功提交的选择；选项只读，隐藏提交答案、完成答题、更正答案等操作。
- 未答题显示“未答”和无用户选择，不显示“回答错误”；完成后的模拟考试可展示当场正确答案及 AI 解析。
- 保留翻译、AI 解析、词汇收藏。辅助内容与历史判分依据分开，更新解析不改作答、成绩或快照。
- 翻译和 AI 解析沿用现有机制；原题已删除或题干、选项与快照不一致时，不把当前题库的辅助内容拼到旧题上，相关调用不可用并说明原因。历史快照本身仍可查看。
- “只读”不能仅隐藏按钮：已完成会话的作答写入仍须由后端拒绝。当前进行中、非模拟、已提交题目的更正答案能力保留，不开放到复盘或累计错题详情。

## 3. 本场题目快照与旧会话

- 新会话保留完整原题成员和顺序，以及每题的题目类型、题干、选项与当场正确答案；包括始终未答的题。
- 工程默认：创建会话时保存本场题目版本，判分使用该版本。进行中现有“更正答案”操作同步更新当前会话该题的判分依据与对错，但不更新其他会话。题库的其他编辑不静默替换本场题目。
- 同场重答仍是最后一次成功提交生效，不新增多次尝试轨迹；完成时冻结每题最终选择、判定或未答状态及本场统计。
- 完成后修改题库或删除单道题目，不改变已冻结的复盘内容和成绩；现有实时作答引用与错题可按删除规则清理，但历史快照不得依赖这些引用才能存续。
- 翻译、AI 解析不纳入冻结的判分依据。复盘区分“当场正确答案”与可能后来变更的题库正确答案。
- 快照只对新会话提供完整保证。启用前已存在或仍在进行中的旧会话不得用当前题库数据伪装成当时快照。
- 无快照旧会话标识“历史题目未保存快照，当前内容可能已变更”；能核实的用户选择和保存判定保留，不以当前正确答案重新判分。
- 旧记录缺失题目或作答时保留原题号并标记“历史记录不完整”；无法确认的状态标为未知／不可用，不按错误或未答推断。保留已保存的本场统计并提示不能逐题完整核对。
- 清空答题历史同时清除对应快照；删除整个考试项目仍清除项目历史，不改变 [ADR-0002](../adr/0002-exam-project-deletion.md) 的删除边界。

快照与旧记录兼容的取舍见 [ADR-0008](../adr/0008-completed-quiz-snapshots.md)。

## 4. 统计与状态一致性

对于完整会话，设总题数为 T、已答数为 A、正确数为 C：

- 错误数 E = A − C；未答数 U = T − A；C + E + U = T。
- 普通练习本场正确率为 C / A；模拟考试本场正确率为 C / T。分母为 0 时显示 0%，不产生 `NaN` 或除零错误；普通练习未提交任何题同时明确标识“未作答”。
- 完成页、详情统计、完成接口、会话详情和历史列表共用该口径；百分比统一保留一位小数，末尾 `.0` 可省略。历史列表的比例文案也必须使用对应分母。
- 例：选 10 题，只答 2 题且全对，普通练习为 100%，模拟考试为 20%；两者都显示正确 2、错误 0、未答 8。
- 保存的 `is_correct` 为 `false` 才是错误。缺失字段、请求失败或旧记录不完整都不是错误结果，不允许前端用布尔兜底静默改判。
- 首页近 100 条作答的正确率、滚动正确率、练习日和当日作答量维持既有定义，不把本场未答题计为作答记录。
- 模拟考试进行中的作答、恢复与复盘相关响应不得提前暴露正确答案、每题对错或可推导成绩的本场正确统计；复盘解锁以服务端完成态为准。

## 5. 本次错题与累计错题

- “本次错题”只含原场最终提交错误的题；原场错后改对的题与未答题不在其中。
- 导航里的累计错题本仍以当前考试项目为边界，题库只是筛选条件；保留标记掌握、错误次数及发起错题练习，不因为本次答对就自动移除。
- 累计错题的题目详情复用相同的只读题目呈现，但不伪造本场成绩或本场题号。
- 用户选择明确标为“最近一次错误答案”，不能冒充最近一次作答。新错误提交只需保留最新错误证据，之后答对不覆写该错误选择，不要求记录全部尝试。
- 有可靠的最近错误题目版本时按该版本对照；旧数据没有可核实的错误选择或不能与显示题目版本对应时，不展示猜测的选择。
- 保持模拟考试的完成前隔离：尚未结束模拟会话的错误证据不能通过累计错题详情提前暴露。

## 6. 原题重做

- 只从已完成的原会话创建新会话；复用全部原题 ID、原顺序、原模式、题数与仍有效的考点上下文，包含原场未答题。
- 不按当前考点重新筛选，不重新抽题，不因错题已标记掌握而排除原题；跨题库错题会话也逐题复用，不能只查首个题库。
- “原题”指题目成员和顺序，不是恢复题库旧版本：新会话使用这些原题当前可用的题干、选项和正确答案，并建立自己的新快照。原场复盘不变。
- 新会话答案为空、进度为起点、正确与已答数为 0；不复制旧选择、耗时或完成态，不覆盖原会话，不在新提交发生前增加作答统计。
- 原场所属用户、考试项目及每道原题的可访问性由服务端校验；客户端不能靠提交任意题目列表跨项目或越权创建。
- 任一原题已删除、无法使用或不再可访问，则整场重开失败，明确指出不可用题目；不跳过、不补抽、不自动恢复原题，也不留下部分新会话。
- 旧会话缺少可核实的原题列表时同样拒绝重开，不通过重新查询题库来猜原范围。考点已删除而题目仍有效时保留原题集合，明确原考点已不可用，不改练其他考点。
- 点击期间禁用重复请求，失败保留原结果页并支持重试；成功后跳转新会话，重新加载也能继续新场答题。

## 8. 验收场景（实施后执行）

| 场景 | 必须满足的结果 |
| --- | --- |
| 模拟 10 题，7 对 3 错后结束 | 完成页 70%，复盘准确区分 7 对与 3 错，正确答案不为空 |
| 模拟未结束，刷新或直接访问结果入口 | 可继续作答，但不能提前查看答案、对错或成绩 |
| 10 题只答 2 题且全对 | 普通 100%、模拟 20%，均为 2 对 0 错 8 未答 |
| 没提交任何答案就结束 | 不崩溃，0%，全部未答，本次错题为空 |
| 跳题、改答、错误筛选 | 显示最终成功提交结果与原场题号，未答不入错误筛选 |
| 完成页与历史入口复盘 | 同一题目与统计口径；只读选项，无提交、完成或更正按钮 |
| 桌面与手机、长英文题干、多选题 | 完整内容可读，导航可用，最终选择与当场正确答案可区分 |
| 完成后修改题干、选项或正确答案 | 有快照的新会话内容与成绩不变；旧会话显示兼容提示 |
| 删除原题后复盘与重做 | 有快照仍可复盘；旧记录缺失显示占位；重做整场失败且不创建部分会话 |
| 原场题库有额外题、原考点成员已变、原场有漏答 | 新场 ID、顺序、模式和题数与原场一致，不重新筛选 |
| 跨题库错题原题重做 | 保留所有原题，不缩成首个题库，已掌握原题也不剔除 |
| 新场首次加载、刷新及提交 | 答案与进度不继承原场；恢复、计时、同场改答与原场历史互不污染 |
| 同题错误后改对／累计错题缺旧选择 | 本次错题按最终结果；最近错误证据不冒充当前选择，未知信息不伪造 |
| 越权、跨项目查看或重做 | 拒绝访问，不返回题目、快照或新会话 |
| 清空历史或删除考试项目 | 对应快照同步删除；首页统计与既有删除规则一致 |

回归覆盖必须保留模拟完成前隔离、已完成会话拒绝提交、同场改答、恢复索引、耗时统计、专项范围和项目权限的既有测试。本轮只检查文档完整性与链接，不执行这些产品验收，也不声称问题已经修复。

## 非目标

不新增多次尝试轨迹，不重算其他会话历史判定，不自动移除后来答对的错题，不回填无法证实的旧题目快照，不修改首页滚动正确率，不恢复已删除题目，不改变整题库或考试项目的既有删除语义，不开展无关前后端重构。
