# 平台题库发布与个人副本：独立来源、不可变快照、按来源只读

[Issue #84](https://github.com/longzhuzhu/quiz-app/issues/84) 要求管理员在独立入口导入、检查和发布可练习题库，登录用户从当前考试项目一键取得个人副本，「勘误和下架不覆盖用户已有答案及学习进度」。

已有 `QuestionBank` 强制归属某个 `Exam`（`exam_id NOT NULL`），个人读写、学习、AI、统计与清理路径全部以项目为边界。把管理员个人项目当作共享空间会泄漏其个人内容，并让平台内容随个人项目或账号生命周期被删除；让 `QuestionBank.exam_id` 可空、再新增「平台类型」则要求上述每条路径都理解特殊平台对象，漏一处即越权。

因此采用**独立平台模型**：

- `PlatformBank` 只保存草稿元数据与目录可选用状态，不归属任何考试项目；创建者只是审计署名，不是内容所有者。
- `PlatformDraftQuestion` 只供管理员维护与导入目标写入，不进入个人题目表。
- `PlatformBankRelease` 保存不可变、完整的题目与展示元数据快照，版本号在来源内递增；目录与选用都只读「最大已提交版本」，不存循环发布指针。

个人副本仍是普通 `QuestionBank` + `Question`，只增加只读的 `source_platform_bank_id` / `source_platform_release_id`，并用 `UNIQUE(exam_id, source_platform_bank_id)` 与来源-版本组合外键保证「同一项目对同一来源只有一份完整副本」且「记录的版本确实属于该来源」。副本使用独立题目 ID，深拷贝题面与来源考点，不复制导入任务、源文件、AI 缓存或学习记录。

**正式内容只读按操作而不是整行判断**：平台副本拒绝增题、通用整题修改、删题、再导入与批量考点打标，但保留专用正确答案更正、题库改名改简介、翻译、AI 解析、词汇与练习。这样既不放开正式内容旁路，也不把辅助学习能力一并冻死。

来源操作不回写个人数据：重新发布只影响后来创建的副本，下架只关闭目录与新建副本，两者都不触碰已有副本、会话或快照，遵守 [ADR-0008](0008-completed-quiz-snapshots.md)；删除副本仍按 [ADR-0002](0002-exam-project-deletion.md) 清理个人数据，随后可从当时最新版本重新选用。平台来源、发布快照与已结束任务不随导入管理员账号删除，只解除署名。

完整需求、技术设计与执行计划见任务 `.trellis/tasks/11-16-platform-question-banks/`。本文只记录决策，不表示相关实现已经上线。
