# 合并只采用代表题的一份附加信息

重复题可能各自积累不同翻译、解析与考点标注。取并集、补齐缺失或逐项裁决可以保留更多内容，但会让清理变成多版本信息整合，并继续阻断大量候选。用户于 2026-10-14 明确选择简化结果：合并时只保留代表题现有的一份翻译、解析、考点及标注来源，其他成员的这些附加信息不迁移、不取并集，其差异本身不阻断合并。

这一选择只覆盖题目的附加信息，不放宽 [学习历史与原题重做保护](0009-question-dedup-preserves-learning-history.md) 或 [答案冲突阻断](0010-question-identity-separate-from-answer-conflicts.md)，也不授权舍弃词汇释义等其他领域内容。回滚备份仍保留恢复所需 pre-image，但不意味着在合并后的业务数据中保留多份附加信息；真实清理依然等待具体清单和执行授权。
