# 账号由管理员创建，不提供自助注册

系统取消了 `/api/auth/register` 与注册页：账号只能由管理员在用户管理页创建，或由运维执行 `backend/scripts/create_user.py`。全新部署的第一个管理员也用该脚本的 `create --admin` 建立。

原实现依靠「第一个注册的用户自动成为管理员」引导系统，这是一个隐式的、任何人只要能访问站点就能抢先占据的提权入口。改为管理员建号后，账号的开通与停用成为一次明确的授权动作：谁有账号、谁被停用，都能在用户管理页看到并追溯。代价是失去用户自助开通的便利，运维必须有人负责建号。

CLI 脚本同时承担救援职责——当没有可用管理员能登录时，只能用 `promote` / `enable` / `reset-password` 恢复，因此它不能只做创建。
