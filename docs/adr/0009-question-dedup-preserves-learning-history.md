# 重复题清理优先保留学习历史与原题重做

nianyu 的 CIPT 题库重复调查中，物理删除重复题虽然能快速减少题目数量，却可能删除关联学习记录、破坏进行中会话，并使原题重做因原题 ID 不再存在而失败。仅保留已完成会话快照不能保留原题重做能力，参见 [ADR-0008](0008-completed-quiz-snapshots.md)。

因此，清理以保留作答、错题、统计、历史复盘及原题重做能力为优先；涉及进行中会话或无法无损处理关联记录的重复组，跳过并报告，不强行删除，也不清空历史或改写冻结快照。这一边界由用户于 2026-10-14 确认，接受首轮不能清理全部重复题的代价。它不表示清理已执行，也不预先决定引入归档、别名或新的持久化模型。
