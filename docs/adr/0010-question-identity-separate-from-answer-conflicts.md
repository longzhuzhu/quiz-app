# 同题身份与正确答案裁决分离

题库中的重复题可能保存了互相矛盾的答案。如果将正确答案作为题目身份的一部分，这些重复会被切成不同题而漏报；但直接按题干、选项合并并默认保留某个答案，又可能把去重变成未经确认的答案更正。

因此，同一用户同一题库内，原始完整题干和保序原始选项一致的记录归入同题组，答案不一致不影响身份。答案冲突是独立的合并阻断项，待用户确认可信答案再处理；AI 可提供建议，不自动裁定或改写答案。该边界由用户于 2026-10-14 确认，接受部分同题暂时无法合并的代价，并继续遵守 [学习历史与原题重做保护](0009-question-dedup-preserves-learning-history.md)。
