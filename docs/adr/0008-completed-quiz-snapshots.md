# 已完成答题按本场快照复盘，不从当前题库重建历史

[Issue #63](https://github.com/longzhuzhu/quiz-app/issues/63) 要求完整、只读的答题复盘。仅保存题目引用并读取当前题库虽然改动小，但后续修改题干、选项、正确答案或删除题目，会使历史内容与已保存的判定不一致；在不重算其他会话历史对错的既有约束下，不能用当前答案去假装当时答案。

因此，新会话保留**本场题目快照**及每题的最终作答、判定和未答状态，完成后冻结；查看详情、本次错题和历史入口使用同一份历史依据。翻译、AI 解析不作为冻结的判分依据。旧会话只展示仍可核实的内容，明确标识无快照或记录不完整，不回填伪造历史。

该决策接受新增持久化与迁移成本，换取可验证的历史语义。删除单道题目不能破坏已完成会话的快照；清空答题历史或删除整个考试项目仍删除对应历史及快照，遵守 [ADR-0002](0002-exam-project-deletion.md)。**原题重做**只复用题目成员、顺序和模式，不复制旧作答或恢复已删除题目；任一原题不可用时拒绝创建新会话。

详细范围、兼容边界与验收场景见[答题复盘与原题重做设计](../plans/2026-10-13-quiz-review-retry-design.md)。决策已确认，本文不表示相关代码已经实现。
