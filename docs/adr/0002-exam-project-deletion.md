# Allow owners to delete exam projects with their data

Every **考试项目** is a user-owned workspace, not shared platform content. The owner may delete the entire **考试项目** together with the project-scoped data it contains, including question banks, questions, wrong-answer records, quiz history, and exam-scoped vocabulary. Cross-exam personal vocabulary remains outside this deletion boundary.

This trade-off favors user control over self-owned spaces. Preventing deletion once a project contains data would leave users unable to clean up experiments, mistaken imports, or abandoned personal study spaces. The cost is that deletion is destructive, so the product must present it as a project-level data deletion rather than a simple hide action.
