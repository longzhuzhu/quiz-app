# 滚动正确率按日快照，不从 answered_at 回放

练习趋势图需要每个本地日一个**滚动正确率**，且事后改答不得改写已经过去的日子。`QuizAnswer.answered_at` 改答会被覆写，按它分日回放会把历史点搬走，与 ADR-0005 同一类错误。按「会话 × 题 × 日」另记全部作答事实可以重算，但图只要 y 值、N 已锁 100，不值第二条作答账；`practice_day_questions` 按题×日去重，也撑不起「近 100 记」。

因此每次提交只把当时的正确率与实际记数写入当天一行快照，只更新今天；空日沿用上一快照；今天这一点仍走与首页正确率卡片相同的现势查询。启用前的日子不回填、不画假趋势。清空答题历史时这些快照与练习日一同清除。
