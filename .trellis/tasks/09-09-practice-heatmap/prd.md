# 考试项目首页练习热力图

## Goal

考试项目所有者打开首页时，能一眼看到自己最近有没有坚持在本项目里练习：一块 GitHub 风格的方格图，空格表示没来，有颜色表示来过，颜色深浅表示当天动过多少题。

## Background

### 当前状态（已核实）

- 考试项目首页是 `frontend/src/views/HomeView.vue`，路由 `/exams/:examSlug/dashboard`。现有顺序：标题 → 四格统计 → 继续答题入口 → 题库列表。没有按日聚合，也没有连续天数。
- 答题写入 `POST /api/quiz/answer`（`backend/app/api/routes/quiz.py:217`）。`QuizAnswer` 以 `(session_id, question_id)` 唯一，改答覆写 `answered_at`（同文件 `:260-264`），不能作为「某天是否练过」的事实来源。见 `docs/adr/0005-practice-days-not-from-last-answered-at.md`。
- 考试上下文 `get_exam_context`（`backend/app/api/deps.py:77`）只返回当前用户自己的考试项目。首页接口天然是所有者视角。
- 清空历史 `DELETE /api/quiz/history`（`backend/app/api/routes/quiz.py:411`）删除本项目会话，级联删除 `quiz_answers`，但不会自动清掉任何独立的练习日记录。
- 删除考试项目走 `delete_exam_data`（`backend/app/services/exam_service.py:230`）。
- 时间戳一律 UTC 存储；历史页用浏览器本地日期显示（`HistoryView.vue` 的 `toLocaleDateString('zh-CN')`）。
- Alembic head 为 `006`。`backend/tests/` 为不连库的纯单元测试。

领域词已写入 `CONTEXT.md`：**练习日**、**练习热力图**、**连续练习日**、**当日作答量**。

## Key Decisions

| # | 决策 | 结论 |
|---|---|---|
| D1 | 产品工作 | 习惯信号（「我最近有没有坚持练」），不是运动量或备考进度 |
| D2 | 统计边界 | 仅当前考试项目；不跨项目加总 |
| D3 | 可见性 | 第一版仅所有者。现有 `get_exam_context` 已按所有者隔离，无需另做管理员视图 |
| D4 | 点亮条件 | 当天在本项目至少提交过一次答案（含改答、各答题模式）；只打开会话不算 |
| D5 | 深浅 | GitHub 五档；**当日作答量** = 当天动过的不重复题目数 |
| D6 | 档位 | 固定尺：0 / 1–3 / 4–9 / 10–19 / 20+，不按窗口或个人历史重算 |
| D7 | 改答 | 可点亮新的练习日，不能取消或搬走已成立的练习日 |
| D8 | 「一天」 | 作答当时设备本地自然日，写入后冻结；打开首页不按当时时区重切 |
| D9 | 一周 | 周一起排 |
| D10 | 窗口 | 桌面近 53 周，手机近 16 周（`md` 断点） |
| D11 | 连续 | 只要当前连续；昨天是练习日则宽限到今天本地午夜 |
| D12 | 交互 | 悬停/长按显示日期和当日作答量，不跳转；不要窗口总量句 |
| D13 | 位置 | 四格统计和继续答题入口之间 |
| D14 | 空态 | 从未作答也画出整窗空格，不附加说明文案 |
| D15 | 清空历史 | 练习热力图所依据的练习日一并清除 |
| D16 | 旧数据 | 不回填功能启用前的 `answered_at` |
| D17 | 外观 | GitHub 绿 + Less/More 图例 + 今天描边 |

## Requirements

- **R1 记录练习日**：每次提交答案时，按客户端给出的作答当日本地日，记下「该用户、该考试项目、该日、该题」；同一题同一天重复提交不增加当日作答量。
- **R2 查询热力图**：所有者可读取本项目近 53 周的稀疏日期列表（有作答的天及当日作答量）以及当前连续练习日。
- **R3 首页展示**：考试项目首页在四格统计与继续答题入口之间展示练习热力图：周一起排、固定五档绿色、今天描边、图例、当前连续 n 天；桌面 53 周、窄屏 16 周。
- **R4 与历史同命运**：清空本项目答题历史时，同步删除本项目的练习日记录。删除考试项目时练习日记录一并消失。
- **R5 不回填**：既有 `quiz_answers.answered_at` 不用于生成历史格子。

## Acceptance Criteria

- [ ] AC1：某题在某本地日首次提交后，该日成为练习日且当日作答量至少为 1；同题同日再提交，当日作答量不变。
- [ ] AC2：周一答过的题，周二在同一会话改答后：周一仍是练习日且当日作答量不减；周二若此前未动过该题则当日作答量 +1。
- [ ] AC3：只创建会话、一次答案都未提交，不产生练习日。
- [ ] AC4：`GET` 热力图在调用方给出 `today` 时，返回从 `today` 往前 53 周内有作答的日期与数量，以及按 D11 算出的 `current_streak`（今天未练但昨天是练习日时，连续仍有效）。
- [ ] AC5：首页热力图位于四格统计和继续答题入口之间；有格子的天按 D6 上色；空窗全灰；今天有描边；有 Less/More 图例；展示当前连续天数，不展示最长连续、不作答总量。
- [ ] AC6：视口 ≥ `md` 展示近 53 周，小于 `md` 展示近 16 周；列从周一起。
- [ ] AC7：悬停（桌面）或等效提示显示该日日期与当日作答量；点击格子不导航。
- [ ] AC8：`DELETE /api/quiz/history` 之后本项目热力图为空、连续为 0。
- [ ] AC9：功能启用前已有的答题记录不出现在热力图中。
- [ ] AC10：缺少 `local_date` 的提交不写练习日（旧客户端兼容），也不报错中断答题。
- [ ] AC11：`alembic downgrade` 去掉本任务迁移后再 `upgrade head` 可完成，存量会话与答案不丢失。

## Out of Scope

- 跨考试项目加总的个人习惯图
- 管理员只读查看他人项目时的热力图
- 按正确数/正确率上色
- 最长连续
- 窗口内作答总量文案
- 点击格子进入按日过滤的历史
- 用现存 `answered_at` 回填
- 独立签到动作（没有单独的「打卡」）
