# Quiz UI 重构优化与验证

## Goal

依据 `.trellis/tasks/10-04-quiz-ui-audit/audit.md` 的审查结论，对前端答题体验做聚焦重构：修复答题可靠性缺陷、建立手机端主操作可达性、恢复错题复盘的完整对比、按信息层级降噪排版；并用构建检查 + 隔离浏览器验证回归。纯前端改动，不改后端 API、不改技术栈、不引入营销站手法。

## Requirements

### R1 可靠性（P1 优先）
- E1：选项激活以原生 input 为唯一状态入口；label 仅扩大点击区；文字、空白、原生控件、键盘各激活一次只产生一次状态变化。
- E2：未答时唯一主操作「提交答案」；提交后主操作变「下一题」；改答必须通过显式「重新作答」次级操作，旧结果保留至新提交成功。
- F1：自动下一题仅在答对时触发；等待期间可取消；自动/手动切题后题干起点进入可见区。
- N1：未提交选择按 questionId 存为会话草稿，切题往返不丢失；草稿不计入已提交进度。
- P1：进度条按已提交数量计算；常驻「已答 x · 未答 y」；「第 n/N 题」仅表达位置。
- U2：QuizView / WrongAnswersView / HistoryView 加载失败显示可重试错误态，不冒充空态或保留陈旧数据。

### R2 手机核心路径
- M1：答题页提供常驻底部操作条（主操作 + 简短进度），正文预留底栏空间；题号网格改为按需展开面板；答题页隐藏全局 MobileNav，避免双底栏。
- M2：错题摘要手机上题干占满宽度，操作与展开控件移到独立行；题号按钮与错题操作按钮触摸目标 ≥44px。
- H1：首页顺序改为 继续上次答题 → 题库操作 → 学习概览（紧凑统计）→ 热力图/趋势；首屏可直达「继续/开始」。

### R3 复习闭环
- O2：提交后全部选项保持正常对比度；用边框 + 轻背景 + 「你的选择 / 正确答案」文本标签表达结果，不只依赖红绿；答对且已选同时说明。
- W2（前端部分）：结果页答题详情不 truncate、可展开完整题干与选项对比（API 已返回 options）；提供「全部 / 只看错题」筛选；统计增加「未答」。
- W3：错题本翻译显隐由同一状态控制题干翻译、选项翻译与按钮文案。

### R4 排版与降噪
- R1：题干常规字重、保留原始换行（whitespace-pre-line）、英文阅读列限制约 65–75ch。
- R2：翻译入口紧邻题干；翻译显隐为会话级偏好，切题/提交不重置。
- O1：选项为 控件/标号/正文 三列布局，标号固定窄列，正文悬挂对齐。
- F2：反馈区先给「你的答案 → 正确答案」对照，AI 解析可折叠、默认收起。
- F3：移除摇晃动画；反馈区加 aria-live；全局尊重 prefers-reduced-motion。
- E3：键盘快捷键：A–D / 1–4 选择选项，Enter 提交 / 下一题；输入焦点时不拦截。
- U1：降噪——去渐变进度条、首页彩色顶条、按钮 emoji、重边框；中性底色 + 单一 primary 操作色，保留对错语义色。
- P2：提供常驻「结束答题」入口；结束前若有未答题弹确认；结果页区分未答。
- H2：题干 → 选项 → 主操作/反馈 → 可展开解析 → 辅助工具的层级固定；每个状态只有一个主动作。

## Acceptance Criteria

- [x] E1/E2/F1/N1/P1/U2 全部落地，符合 audit.md「后续若实施的验收建议」对应条目。
- [x] 选项文字、空白、原生 checkbox/radio、键盘激活各一次，仅产生一次状态变化（多选文字点击/复选框点击/键盘 A 验证通过）。
- [x] 草稿切题往返保留；草稿不计入「已答」统计与进度条。
- [x] 跳至任意未答题时位置与进度正确显示（进度 ≠ 位置；题号面板跳题验证通过）。
- [x] 错题答错后不自动跳题；答对且开启自动时 1.5s 后跳转，期间可取消；切题后题干回到视口顶部。
- [x] 手机 390×844 与 320 宽度下：主操作常驻可见不被遮挡；错题题干全宽（320 宽下 256px，原 122px）；首页首屏有继续/开始入口。
- [x] 提交后未选干扰项文字保持正常对比度，并有「你的选择/正确答案」文本标签。
- [x] 结果页详情可展开完整题干与选项对比；统计含未答。
- [x] 翻译按钮文案与题干/选项翻译实际显隐一致（答题页与错题本两处）。
- [x] console 无新增 error/warning（桌面与手机会话均 0 errors / 0 warnings）；`npm run build` 通过。
- [x] 模拟考试模式（已选标签、无对错反馈）、更正答案流程（PUT 写回 + toast + 标签更新）、复制题目（剪贴板含题干与选项）回归正常。
- [x] 明暗两种模式检查主要页面无样式破损（答题/首页/错题本/结果页截图核验）。
