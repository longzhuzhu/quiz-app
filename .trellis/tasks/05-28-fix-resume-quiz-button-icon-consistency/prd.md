# Fix Resume Quiz Button Icon Consistency

## Goal

让首页题库卡片中的题库级“继续答题”按钮与“顺序练习”按钮的图标风格保持一致，避免同一按钮组里一个有图标、一个无图标导致视觉不协调。

## Requirements

- 题库卡片中的题库级“继续答题”按钮需要带图标。
- 图标风格与同一按钮组里的“▶ 顺序练习”、“🔀 随机练习”、“📝 模拟考试”保持一致。
- 不改变按钮行为、显示条件、进度文案或跳转逻辑。
- 不改变全局“继续上次答题”卡片的按钮样式。

## Acceptance Criteria

- [ ] 有未完成普通会话的题库卡片显示带图标的“继续答题”按钮。
- [ ] 题库级“继续答题”和同组练习按钮在视觉语言上保持一致。
- [ ] 点击题库级“继续答题”仍跳转到原会话恢复路由。
- [ ] 前端构建通过。

## Technical Approach

在 `frontend/src/views/HomeView.vue` 中，只调整题库列表卡片里的题库级继续按钮文案，例如改为 `▶ 继续答题`，与现有 `▶ 顺序练习` 的图标风格一致。

## Break-loop Focus

这类问题属于 UI microcopy/icon consistency 漏洞：新增按钮时只满足功能，没有检查同一按钮组内既有视觉语言。修复后应把“同组操作按钮图标/文案风格一致”沉淀到前端规范。
