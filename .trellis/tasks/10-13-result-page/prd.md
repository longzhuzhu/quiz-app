# 完成页统计与本次错题入口

## Goal

改造答题完成页：正确／错误／未答**分列展示**，正确率按模式取分母；提供「查看详情」「本次错题」「再来一次」「返回首页」四个入口。修复「模拟考试结果全部显示错误」。

## Background

父任务：`.trellis/tasks/10-13-quiz-review-retry`（Issue #63）。

现状（`frontend/src/views/QuizResultView.vue`）：

- 统计只有「总题数／正确／错误」三列（`:41-54`），错误数按 `answered_count - correct_count` 推导（`:51`），**没有未答**。
- 详情列表 `max-h-64` 且题干 `truncate` 截断（`:59,66`），且对缺失的 `a.is_correct` 走错误分支渲染（`:62-64`）——直接原因就是后端在模拟完成后仍隐藏 `is_correct`。
- 只有三个按钮（`:76-80`）：返回首页、查看错题（跳项目**累计**错题本，`:78`）、再来一次。
- 「再来一次」调 `quizStore.startQuiz(bank_id, mode)`（`:134`），**只传两个参数**，重新抽题，丢失原题集合与题数。

## 依赖

**前置子任务：**

1. `10-13-review-api` —— 提供新统计字段（`wrong_count`、`unanswered_count`、`accuracy_basis`）与完成态释放的对错。
2. `10-13-retry-api` —— 提供 `POST /quiz/retry`。

`10-13-review-ui` 提供复盘页路由 `ExamQuizReview`；「查看详情」与「本次错题」都跳转到它（`?filter=wrong` 直达错误筛选）。

**文件归属**（避免与 `10-13-review-ui` 并行冲突）：本任务拥有 `QuizResultView.vue`、`stores/quiz.js`、`utils/examRoutes.js`；`review-ui` 拥有新页面、新组件与路由注册。

## Requirements

### R1 — 统计展示

- 三列改为**正确／错误／未答**，数值直接取自后端 `correct_count`、`wrong_count`、`unanswered_count`。
- **不在前端重算**错误数与分母；`accuracy` 直接消费后端值。
- 正确率口径由后端按模式决定（普通练习用已答数为分母，模拟考试用总题数为分母）。
- 分母为 0（零答案结束）时显示 0%，不产生 `NaN`。
- 圆环与配色阈值沿用现有实现（`:104-116`），不引入新视觉体系。

### R2 — 移除内嵌截断详情

删除 `:56-73` 的答题详情列表。完整内容由复盘页承担，避免同一信息两套呈现。

### R3 — 四个入口

| 按钮 | 行为 |
| --- | --- |
| 查看详情 | 跳复盘页 `ExamQuizReview`，默认「全部」筛选 |
| 本次错题 | 跳复盘页并默认选中「错误」筛选（`?filter=wrong`） |
| 再来一次 | 调 `POST /quiz/retry`，成功后跳新会话答题页 |
| 返回首页 | 跳 `dashboard`，行为不变 |

- 「本次错题」**不再**跳项目累计错题本。
- 空状态由复盘页处理（没有错题时显示明确空状态），完成页不做特殊分支。
- 保留「加载失败，请返回重试」的错误态（`:9-13`）。

### R4 — 再来一次

- 调用新端点 `POST /quiz/retry`，body `{session_id}`。
- **不**再传 `bank_id + mode` 重新抽题。
- 请求期间**禁用按钮**，防止重复点击创建多场会话。
- 失败时**留在当前结果页**并提示原因（例如哪些原题不可用），**不**跳转、不清空页面。
- 成功后跳转新会话答题页（`quizStore.session.id`）。
- `startQuiz` 的既有签名与调用方（题库页等入口）**保持不变**。

### R5 — 历史入口同步

`HistoryView.vue` 的已完成会话跳转目标由 `quizResult` 改为复盘页；未完成会话不在历史列表出现，无需处理。

## Acceptance Criteria

- [ ] 模拟 10 题 7 对 3 错完成后：完成页显示 70%、正确 7、错误 3、未答 0。
- [ ] 10 题只答 2 题全对：普通练习显示 100%、模拟显示 20%；两者均为正确 2、错误 0、未答 8。
- [ ] 零答案结束：显示 0%，正确 0、错误 0、未答等于总题数，页面不崩溃、无 `NaN`。
- [ ] 完成页**不再**出现截断的答题详情列表。
- [ ] 「查看详情」进入复盘页且默认全部筛选。
- [ ] 「本次错题」进入复盘页且默认错误筛选。
- [ ] 「再来一次」调用 `/quiz/retry`；新会话题数与原场一致，模式相同。
- [ ] 「再来一次」请求期间按钮禁用；连点不会创建多场会话。
- [ ] 「再来一次」失败时留在原页并提示，页面内容不被清空。
- [ ] 跨题库错题会话的「再来一次」保留全部原题。
- [ ] 原题已删除时「再来一次」失败并提示不可用题目。
- [ ] 「返回首页」行为不变。
- [ ] 历史页已完成会话进入复盘页，不再进结果页。
- [ ] 前端测试与构建通过：`cd frontend && npm test && npm run build`。
