# 答题复盘与原题重做（Issue #63）

## Goal

让用户结束答题后能区分**正确**、**错误**与**未答**，查看完整题干、选项、最终选择及**当场正确答案**，并按**原题原序**另开一场练习。所有答题模式统一完成页与复盘规则；模拟考试结束前继续隐藏答案和对错。

## Confirmed Facts

- 模拟考试完成后仍隐藏对错：`session_detail` 只按 `mode == "exam"` 隐藏字段，不区分完成态（`backend/app/api/routes/quiz.py:554,571-575`）；前端对缺失的 `is_correct` 走错误分支（`frontend/src/views/QuizResultView.vue:62-64`）。这是「全部显示错误」的直接原因。
- 答案查询无 `order_by`（`quiz.py:556`），结果页却按数组下标编号（`QuizResultView.vue:60,66`）；跳题、改答、随机模式会造成题号错位。
- 已完成会话不返回完整题目（`quiz.py:578-604` 仅在未完成时返回 `questions`）；结果页容器 `max-w-lg` 与 `max-h-64`、题干 `truncate` 使完整内容不可读。
- 正确率不分模式，统一用已答数为分母（`quiz.py:416,468,617`）。
- `QuizSession` 只存题目 ID 与作答记录，无内容快照（`backend/app/models/quiz.py:12-72`）；详情实时读取当前题库（`quiz.py:562-575`）。
- 删除题目直接删除该题全部 `QuizAnswer`，不修会话 `question_ids` 与计数（`backend/app/api/routes/questions.py:186-191`）。
- 错题接口不返回 `user_answer` 或 `session_id`（`backend/app/api/routes/wrong.py:67-85`）。
- 「再来一次」只传题库与模式，重新抽题（`QuizResultView.vue:134`；`frontend/src/stores/quiz.js:11-21`）；跨题库错题会话的 `bank_id` 只是首个题库（`wrong.py:114`）。
- 前端无独立复盘路由，无只读题目组件（`QuestionCard.vue` 无 `readonly` prop，已答后仍可退回编辑态：`:280-283`）。
- 模拟考试进行中隔离是既有明确设计（`quiz.py:370-377`；`QuizView.vue:232-233`），必须保留。

## Requirements

需求全文以 `docs/plans/2026-10-13-quiz-review-retry-design.md` 为准，此处只列 R1–R8 标题与不可协商的约束。

### R1 — 本场题目快照与完成冻结

新会话保留完整原题成员与顺序，以及每题题目类型、题干、选项与**当场正确答案**，包含始终未答的题。完成后冻结最终作答、判定或未答状态与本场统计。完成后修改题库或删除单道题目，不改变已冻结的复盘内容与成绩。翻译与 AI 解析**不纳入**冻结的判分依据。

### R2 — 旧会话兼容边界

快照只对新会话提供完整保证。启用前已存在或仍在进行的旧会话**不得**用当前题库数据伪装成当时快照；显示「历史题目未保存快照，当前内容可能已变更」；记录不完整时保留原题号并标记，无法确认的状态标为未知／不可用，不按错误或未答推断，不重新判分，不回填伪造历史。

### R3 — 统一复盘 API 与统计口径

已完成的会话按快照返回完整题目（含未答）、最终作答、判定与当场正确答案，并**按 `session.question_ids` 排序编号**。区分进行中与已完成：进行中的模拟考试继续隐藏答案、对错与可推导成绩的统计；复盘解锁以服务端完成态为准。已完成会话的作答写入必须由**后端拒绝**，不能只隐藏前端按钮。

统计口径：设总题数 T、已答数 A、正确数 C，则错误数 E = A − C，未答数 U = T − A，C + E + U = T。普通练习本场正确率为 C / A，模拟考试为 C / T；分母为 0 时显示 0%，不产生 `NaN` 或除零错误。百分比保留一位小数，末尾 `.0` 可省略。保存的 `is_correct` 为 `false` 才是错误；缺失字段、请求失败或旧记录不完整都**不是**错误结果，前端不得用布尔兜底静默改判。

### R4 — 原题原序重开

只从已完成的原会话创建新会话，复用**全部**原题 ID、原顺序、原模式、题数与仍有效的考点上下文，包含原场未答题。不按当前考点重新筛选，不重新抽题，不因错题已标记掌握而排除原题，跨题库错题会话逐题复用。新会话答案为空、进度为起点、计数为 0，不复制旧选择或耗时，不覆盖原会话。原场所属用户、考试项目及每题可访问性由**服务端**校验。任一原题已删除、不可用或不可访问则整场失败并指出不可用题目，不跳过、不补抽、不自动恢复、不留下部分新会话。旧会话缺少可核实原题列表时同样拒绝，不通过查询题库猜原范围。点击期间禁用重复请求，失败保留原结果页并支持重试。

### R5 — 只读复盘体验

复盘沿用答题页的一题一页、上一题／下一题与题号导航；桌面保留题号侧栏，手机单列并保留可访问的题号导航；长题干与选项不得截断或被固定导航遮挡。支持全部／正确／错误／未答筛选；「本次错题」默认选中错误筛选；筛选后保留**原场题号**，不按筛选数组重新编号。显示原场最后一次成功提交的选择；选项只读，隐藏提交答案、完成答题、更正答案。未答题显示「未答」与无用户选择，不显示「回答错误」。保留翻译、AI 解析、词汇收藏；辅助内容与历史判分依据分开，更新解析不改作答、成绩或快照。

### R6 — 完成页与本次错题

完成页提供「查看详情」「本次错题」「再来一次」「返回首页」；正确／错误／未答分列展示。本次错题只含原场最终提交错误的题；原场错后改对的题与未答题不在其中；空状态明确，不得跳到累计错题本补内容。累计错题本仍以当前考试项目为边界、题库只作筛选，保留标记掌握、错误次数与发起错题练习；其题目详情复用相同只读呈现，但不伪造本场成绩或本场题号，用户选择标为**最近一次错误答案**。保持模拟考试完成前隔离：未结束模拟会话的错误证据不能通过累计错题详情提前暴露。

### R7 — 入口统一

查看详情、查看本次错题与已完成历史会话进入**同一套**复盘体验；进行中会话继续进入答题页，不能借结果页提前查看答案。正确率规则同步到完成页与历史记录；首页近 100 条作答的正确率、滚动正确率、练习日与当日作答量维持既有定义，不把本场未答题计为作答记录。

### R8 — 删除与清理边界

清空答题历史同时清除对应快照；删除整个考试项目仍清除项目历史，不改变 `docs/adr/0002-exam-project-deletion.md` 的删除边界。删除单道题目不破坏已完成会话的快照。

## 约束

- 遵守 `CONTEXT.md` 领域词汇与 Avoid 约定；「本场正确率」不得写成「准确率」或与首页「滚动正确率」混用。
- 不改变考试项目 URL 与权限边界，不保留旧路由，遵守 `docs/adr/0003-url-exam-slug-and-active-exam.md` 与 `0004-no-legacy-routes-for-multi-exam.md`。
- 模拟考试进行中不得提前暴露正确答案、每题对错或可推导成绩的统计。
- 跨层契约变更（模型、schema、API、前端消费）必须四层同步，不能只改一侧。

## 任务地图

父任务持有需求集、任务地图与跨子任务验收；实施由 5 个子任务承担。**父子结构不是依赖系统，顺序写在子任务自己的 `prd.md` 与 `implement.md` 里。**

| 子任务 | 交付物 | 依赖 |
| --- | --- | --- |
| `10-13-snapshot-model` | 本场快照持久化、完成冻结、Alembic 迁移 | 无（起点） |
| `10-13-review-api` | 复盘详情 API、统计口径、只读写入拒绝 | 依赖 snapshot-model 的数据结构 |
| `10-13-retry-api` | 原题原序重开 API、失败语义 | 依赖 snapshot-model；复用 review-api 的口径工具 |
| `10-13-review-ui` | 只读复盘页面、筛选、题号导航 | 依赖 review-api 的响应契约 |
| `10-13-result-page` | 完成页统计与四个入口 | 依赖 review-api 响应契约与 retry-api 端点 |

`10-13-retry-api` 与 `10-13-review-api` 都在 `backend/app/api/routes/quiz.py` 工作，`10-13-review-ui` 与 `10-13-result-page` 都会触及前端答题相关视图。子任务应在各自 `implement.md` 写明「先确认依赖子任务已合入或明确约定接口」，避免并行改同一文件时冲突。

## Acceptance Criteria

完整场景表见设计文档第 8 节。跨子任务验收以下列端到端场景为准，全部通过才算父任务完成：

- [ ] 模拟 10 题，7 对 3 错后结束：完成页 70%，复盘准确区分 7 对与 3 错，正确答案不为空。
- [ ] 模拟未结束，刷新页面或直接访问结果入口：可继续作答，但不能提前查看答案、对错或成绩。
- [ ] 10 题只答 2 题且全对：普通练习 100%、模拟考试 20%，两者都显示 2 对 0 错 8 未答。
- [ ] 没提交任何答案就结束：不崩溃，0%，全部未答，本次错题为空。
- [ ] 跳题、改答、错误筛选：显示最终成功提交结果与原场题号，未答不入错误筛选。
- [ ] 完成页与历史入口复盘：同一题目与统计口径；只读选项，无提交、完成或更正按钮。
- [ ] 桌面与手机、长英文题干、多选题：完整内容可读，导航可用，最终选择与当场正确答案可区分。
- [ ] 完成后修改题干、选项或正确答案：有快照的新会话内容与成绩不变；旧会话显示兼容提示。
- [ ] 删除原题后复盘与重做：有快照仍可复盘；旧记录缺失显示占位；重做整场失败且不创建部分会话。
- [ ] 原场题库有额外题、原考点成员已变、原场有漏答：新场 ID、顺序、模式和题数与原场一致，不重新筛选。
- [ ] 跨题库错题原题重做：保留所有原题，不缩成首个题库，已掌握原题也不剔除。
- [ ] 新场首次加载、刷新及提交：答案与进度不继承原场；恢复、计时、同场改答与原场历史互不污染。
- [ ] 同题错误后改对／累计错题缺旧选择：本次错题按最终结果；最近错误证据不冒充当前选择，未知信息不伪造。
- [ ] 越权、跨项目查看或重做：拒绝访问，不返回题目、快照或新会话。
- [ ] 清空历史或删除考试项目：对应快照同步删除；首页统计与既有删除规则一致。

回归必须保留：模拟完成前隔离、已完成会话拒绝提交、同场改答、恢复索引、耗时统计、专项范围和项目权限的既有测试。

## 非目标

不新增多次尝试轨迹，不重算其他会话历史判定，不自动移除后来答对的错题，不回填无法证实的旧题目快照，不修改首页滚动正确率，不恢复已删除题目，不改变整题库或考试项目的既有删除语义，不开展无关前后端重构。
