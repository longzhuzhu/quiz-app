# 答题面：更新解析、复制图标、更正答案

## Goal

让考试项目所有者在答题卡片上更快地复制题目、更新解析，并在发现题库**正确答案**写错时当场**更正答案**。同时让新生成的 **AI 解析**不再被库内当前答案带偏：提示词不写入**正确答案**，模型独立给出**模型认定答案**；与库内答案不一致时标出**答案冲突**，而不是把解析掰回去护那个可能错误的答案。

## Background and Confirmed Facts

- 答题卡片在 `frontend/src/components/QuestionCard.vue`。`ExplainButton` 答题页与错题本共用（`QuestionCard.vue:56-63`、`WrongAnswersView.vue:137-142`）。
- 已显示解析后按钮文案是「更新AI解析」（`ExplainButton.vue:32-36`）。术语表中该操作叫**更新 AI 解析**，答题面短写为「更新解析」。
- 复制按钮在 AI 按钮行，带「复制」文字（`QuestionCard.vue:65-72`）。复制内容是题干 + 选项，不含答案和解析（`QuestionCard.vue:207-221`）。「已答 n 次」在页眉右侧（`QuestionCard.vue:14-16`）。
- 模拟考试隐藏解析按钮（`QuestionCard.vue:57`），复制目前仍显示。提交后点击选项会清掉对错反馈、变成改答（`QuestionCard.vue:190-193`）。
- 题库**正确答案**已能通过 `PUT /api/questions/{id}` 修改；改答案会清空该题 **AI 解析**（`questions.py:127-130`）。权限是**考试项目所有者**（`get_exam_context` 按 `owner_id=current_user.id`），不是 `is_admin`。管理员看别人的项目只读，走不了答题接口。因此答题页上「只给所有者」等于每位练习者提交后都能看到「更正答案」（模拟考试除外）。
- 提交答案写入本场 `QuizAnswer.is_correct` 和 `session.correct_count`；答错才追加错题本，答对不移除错题（`quiz.py:262-306`）。同一题再提交会再加错次。
- AI 解析 user 提示词目前包含 `正确答案：{question.correct_answer}`（`ai_service.py:497`）。结构校验按库内答案划分干扰项（`ai_service.py:431-455`）。不合格会纠正重试一次，结果是解析被掰去护库内答案。
- 平台输出契约在运行时拼到 persona 后（`exam_service.py:86-92`）。`004` tripwire 锁的是当时的 persona+契约全文。存量解析没有**模型认定答案**，无法标冲突。
- 术语与关系已写入 `CONTEXT.md`：**正确答案**、**更正答案**、**模型认定答案**、**答案冲突**、**更新 AI 解析**。

## Key Product Decisions

- 「更新AI解析」改为「更新解析」；首次仍叫「AI 解析」。错题本共用同一按钮，文案一起变。
- 复制改为页眉「已答 n 次」旁的图标按钮；复制内容不变。模拟考试保留。错题本列表不加复制。
- **更正答案**改题库**正确答案**，不是只改这一次判分，也不要求 `is_admin`。
- 仅非模拟考试、提交后出现，放在对错反馈里紧挨「正确答案: X」。**答案冲突**不另做第二个按钮。
- 点选项选定新答案（多选可多点），写入前用 `ConfirmDialog` 确认从哪一组改到哪一组。
- 更正后：卡片对错和本场该题 `QuizAnswer.is_correct` / `session.correct_count` 立刻按新答案重算；该题 **AI 解析**清空且不自动再生成；错题本不加次、不自动移除；其他场次不动。
- 新生成解析的提示词不写入库内**正确答案**。模型必须返回**模型认定答案**。结构校验按**模型认定答案**划分干扰项，不按库内答案。库内对照只用于检测**答案冲突**：不一致则保留解析原文并在展示文本开头标冲突，不因此重试。
- 旧解析继续展示、不标冲突；点「更新解析」后才按新规则生成。
- 有冲突时「更正答案」预选**模型认定答案**；无冲突时预选当前库内**正确答案**。
- 错题本本轮不加「更正答案」。

## Requirements

1. **更新解析文案**：`ExplainButton` 在已显示解析时文案为「更新解析」（loading 时仍为「更新中...」）；未显示时保持「AI 解析」/「解析中...」。
2. **复制入口**：从 AI 按钮行移除带文字的复制按钮；在页眉「已答 n 次」旁放仅图标的复制按钮，`aria-label` 为「复制题目」。点击后行为与现网一致（题干+选项、成功/失败 toast）。
3. **更正答案入口**：`QuestionCard` 在 `answered && !examMode` 的对错反馈中提供「更正答案」。进入更正态后，点击选项只改待写入的新**正确答案**，不得清掉当前对错反馈、不得改用户作答。
4. **更正答案写入**：确认后把新选项集合写成该题**正确答案**（格式与现网一致，如 `B` / `A,C`）。空选择不能确认。新答案与当前相同时视为无操作，不清解析。
5. **更正后本场重判**：当前卡片的对错文案、选项颜色、「正确答案: X」立即更新；本场该题作答对错和本场答对题数一并更新。不得走完整提交逻辑（不得再记一次错题、不得增加已答次数）。
6. **更正后解析**：该题已有 **AI 解析**清空，页面不再显示旧解析；不自动调用生成。
7. **解析提示词脱钩**：`explain_question` 发给模型的 user 消息只含题干和选项，禁止出现库内**正确答案**。纠正重试消息同样不得补回库内答案。
8. **模型认定答案**：新生成 JSON 必须包含 `judged_answer`（选项 key，单选/判断一个，多选逗号分隔）。结构校验按它划分干扰项；缺、空、或包含不存在的 key 则不合格，可走现有一次纠正重试。
9. **答案冲突**：`judged_answer` 与库内**正确答案**（规范化后）不一致时，仍将合格解析落库；在中文展示文本开头用服务端固定版式标出题库答案与 AI 认定，不重试、不改写解析正文去护库内答案。一致时不插入该段。
10. **冲突预选**：从展示文本解析出**模型认定答案**后，所有者点「更正答案」时预选该组选项；没有冲突段时预选当前库内答案。
11. **旧缓存**：没有冲突段的存量解析原样展示；首次「AI 解析」仍可返回缓存。只有新生成或主动**更新 AI 解析**才带**模型认定答案**并对冲突。

## Acceptance Criteria

- [ ] 解析已显示时按钮为可点的「更新解析」；未显示时仍为「AI 解析」。答题页与错题本一致。
- [ ] 答题卡片页眉「已答 n 次」旁有复制图标、无「复制」文字；AI 按钮行不再有复制。点击后剪贴板含题干和选项，成功/失败 toast 与现网一致。模拟考试仍可复制。
- [ ] 非模拟考试提交后，对错反馈中「正确答案: X」旁出现「更正答案」；模拟考试与未提交时不出现。
- [ ] 进入更正态后点选项不会变成改答；确认框文案包含旧答案和新答案；确认后题库**正确答案**变为所选。
- [ ] 更正成功后当前题对错反馈与选项颜色按新答案更新；刷新后本场该题对错与更正后一致；错题本次数不因这次更正增加；已答次数不增加。
- [ ] 更正成功后该题 **AI 解析**不再显示，数据库中该题解析字段被清空。
- [ ] 新生成或更新解析时，发给模型的提示词不含库内**正确答案**。
- [ ] 模型认定与库内答案不一致时，解析正文仍按模型判断展示，文首出现固定**答案冲突**段；该次请求不会因为冲突而再调一次模型去护库内答案。
- [ ] 有冲突时点「更正答案」预选 AI 认定的选项；无冲突时预选当前库内答案。
- [ ] 存量无冲突段的解析首次点击仍展示旧文案，不出现**答案冲突**；点「更新解析」成功后才按新规则对照。

## Out of Scope

- 错题本列表不加复制、不加「更正答案」。
- 不批量清空或重写未更新的历史 **AI 解析**。
- 不重算其他会话的历史对错，不自动把错题标为已掌握或删除。
- 不改模拟考试隐藏解析、不返回正确答案的规则。
- 不在题目管理页改交互；整题编辑入口保留。
- 不新增 Markdown 渲染。
- 不为「更正答案」做审计日志或填写更正原因。
