# 考试项目首页练习趋势图

## Goal

考试项目所有者打开首页时，能在练习热力图右侧看到近 30 个本地日的练题趋势：一条是当日作答量，一条是与四格卡片同一口径的滚动正确率。

## Background

- 首页顺序：四格统计 → 练习热力图 → 继续答题 → 题库。热力图只表达「哪天来过、当天多忙」，没有时间形状。
- **当日作答量**已落在 `practice_day_questions`，不回放 `answered_at`（ADR-0005）。
- 四格**正确率**是当前考试项目最近 100 条仍存在的作答记录的答对比例；同一会话改答只留最后一次。
- 领域词与关系见 `CONTEXT.md`。存储取舍见 `docs/adr/0006-rolling-accuracy-daily-snapshot.md`。

## Key Decisions

| # | 决策 | 结论 |
|---|---|---|
| D1 | 位置 | 热力图右侧；桌面左右等宽等高；窄屏上热力图、下趋势图 |
| D2 | 窗口 | 近 30 个本地日，按日一点；不跟热力图 53/16 周对齐 |
| D3 | 题数 | **当日作答量**（不重复题） |
| D4 | 正确率 | **滚动正确率**，与卡片同一口径；N 锁 100 |
| D5 | 画法 | 一张图、双纵轴（左题数、右 %） |
| D6 | 空日 | 30 天都打点；题数 0，正确率沿用上一日 |
| D7 | 历史 | 按日冻结；今天这一点走卡片现势 |
| D8 | 存储 | 按日快照，不回放 `answered_at`，不作答流水 |
| D9 | 上线 | 不编造启用前的正确率形状；从第一个可冻结点起画 |
| D10 | 旧作答 | 计入正确率，不产生当日作答量 |
| D11 | 卡片 | 四格正确率保留 |
| D12 | 交互 | 只悬停；不跳转 |
| D13 | 文案 | 无「连续 n 天」；图例为当日作答量、「近 100 记正确率」 |
| D14 | 命运 | 所有者可见；清历史与热力图、卡片一同归零；从未作答画空轴 |

## Requirements

- **R1 快照**：每次提交答案且本地日合法时，把当时的正确率与实际记数写入该本地日一行；只更新该日，不改更早的日。
- **R2 查询**：所有者可读取近 30 个本地日的密集序列：每日当日作答量，以及按 D6–D9 展开的滚动正确率。
- **R3 首页**：四格与继续答题之间，热力图与趋势图并排（窄屏上下）。
- **R4 同命运**：清空本项目答题历史时删除快照。删除考试项目时快照随 FK 消失。
- **R5 不回放**：不用 `answered_at` 回填历史正确率形状。

## Acceptance Criteria

- [ ] AC1：合法本地日提交后，该日快照存在；再提交同一日只更新该日快照，更早快照不变。
- [ ] AC2：`GET` 趋势在给出 `today` 时返回连续 30 个本地日；无练习日的日子 `count` 为 0。
- [ ] AC3：今天的正确率与 `GET /recent-accuracy`（N=100）一致；有作答时最后一点对得上四格卡片。
- [ ] AC4：无快照的历史日正确率为空，不画 0% 假悬崖；有快照之后的空日沿用上一快照。
- [ ] AC5：首页桌面左右等宽并列，窄屏趋势图在热力图下；图例为当日作答量与近 100 记正确率。
- [ ] AC6：悬停或点到具体点时只展示该点数值（`答题数：n题` / `正确率：n%`），不叠另一条线、不展示日期；点击不导航。
- [ ] AC7：`DELETE /api/quiz/history` 后趋势 30 日题数全 0、正确率无点，卡片为 0%。
- [ ] AC8：非法或缺失 `local_date` 不写快照，也不打断答题。
- [ ] AC9：`alembic downgrade` 去掉本任务迁移后再 `upgrade head` 可完成。

## Out of Scope

- 可调 N
- 点击某日过滤历史或展开 100 记
- 用 `answered_at` 回填正确率
- 跨考试项目加总
- 管理员只读他人项目时的趋势图
- 改四格正确率算法
